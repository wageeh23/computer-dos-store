# Computer DOS Store — متجر وتجميعات PC

نظام متكامل لمحل قطع كمبيوتر وإكسسوارات، بقسمين:

- **متجر عام** (بدون دخول) بثيم ألعاب RGB متحرك: مُجمّع PC بفحص توافق ذكي، باندلز جاهزة، سيتب ستريمرز، توصية تجميعة بالميزانية، وتصور السيتب بالذكاء الاصطناعي.
- **لوحة تحكم** `/admin` (محمية بدخول): مخزون ومنتجات بمواصفات توافق، فواتير بيع/شراء مع طباعة، عملاء وموردون وديون، إدارة باندلز، مُجمّع يحوّل لفاتورة، وتقارير مبيعات وأرباح.

يعمل على **الويب** + **ويندوز** (Setup.exe) + **أندرويد** (PWA الآن / APK عبر Capacitor).

## المكونات

| المجلد | الوصف |
|---|---|
| `server/` | سيرفر Express + SQLite مدمجة (node:sqlite) — API عام + محمي |
| `client/` | React + Vite + Tailwind — متجر RGB عام + لوحة تحكم عربية RTL |
| `electron/` | تطبيق سطح المكتب (يتصل بالسيرفر) |
| `android/` | مشروع أندرويد Capacitor الجاهز |

## التشغيل

### 1) السيرفر + الويب

```bash
npm install
npm run build     # بناء الواجهة (تشمل PWA)
npm start         # http://localhost:3000
```

- المتجر العام: `http://localhost:3000/` — ومن أجهزة الشبكة: `http://<IP>:3000`
- لوحة التحكم: `http://localhost:3000/admin` — دخول `admin` / `admin123` (غيّرها فوراً)

### 2) تطبيق ويندوز + Setup.exe

```bash
npm run dist      # ينتج release\Computer DOS Store Setup 1.0.0.exe
```

ثبّته على أي جهاز، أدخل عنوان السيرفر في شاشة الاتصال، ويمكن تغييره من القائمة.

### 3) أندرويد

**PWA (فوري — بدون أدوات):** افتح `http://<IP-السيرفر>:3000` في كروم على الهاتف → قائمة المتصفح → «تثبيت التطبيق / Add to Home screen». يعمل بأيقونة وملء الشاشة وكاش أوفلاين للواجهة.

**APK حقيقي (Capacitor):** يحتاج Android Studio مثبتاً:

```bash
# عدّل capacitor.config.json وأضف عنوان سيرفرك:
#   "server": { "url": "http://192.168.1.101:3000" }
npm run build
npx cap sync
npm run cap:android   # يفتح Android Studio → Build → Build APK
```

> السيرفر يجب أن يعمل ويكون الهاتف على نفس الشبكة (أو عنوان عام للسيرفر المستضاف).

### وضع التطوير

```bash
npm run dev   # سيرفر (3000) + Vite dev (5173)
```

## الميزات التقنية

- **فحص التوافق** (`client/src/lib/compat.js`): socket معالج/لوحة، نوع الرام DDR، حجم اللوحة/الصندوق، طول كرت الشاشة، قدرة المزود مقابل TDP، دعم المبرد، خانات M.2 — أخطاء تمنع وتنبيهات تحذر.
- **التوصية الذكية** (`lib/recommend.js`): ميزانية + استخدام (ألعاب/ستريمنج/مونتاج/مكتبي) → توزيع أوزان → أفضل قطع متوافقة متوفرة بالمخزون.
- **تصور AI** (`lib/ai.js`): صورة السيتب من pollinations.ai المجاني — بدون مفتاح، يحتاج إنترنت.
- **مواصفات المنتجات**: لكل فئة slugs وحقول specs ديناميكية في نموذج المنتج بالأدمن.
- **الأنيميشن**: framer-motion (انتقالات/قوائم) + GSAP (خلفية متوهجة وhero) + حدود RGB conic-gradient + glassmorphism.

## البيانات والنسخ الاحتياطي

- قاعدة البيانات: `data/store.db` — للنسخ الاحتياطي انسخ الملف.
- يحتوي بيانات تجريبية (28 قطعة متوافقة + باندلان) للتجربة الفورية — احذفها من الأدمن عند إدخال منتجاتك الحقيقية.
- متغيرات بيئة: `PORT`, `DATA_DIR`, `DB_PATH`.

## التخصيص

- اسم المحل/العملة/الهاتف: `client/src/config.js`
- فئات وخانات المُجمّع والتوافق: `client/src/lib/catalog.js`
- ثم `npm run build` و`npm run dist` لإعادة الإنتاج.
